# Sidewalk Stories LA

**Repairing broken sidewalks. Building community. One mosaic at a time.**

Sidewalk Stories LA is a California nonprofit public benefit corporation that repairs damaged sidewalk panels in Los Angeles and transforms them into community-built mosaic art designed and installed by neighborhood youth working alongside professional teaching artists and licensed concrete crews.

---

## Our Model

1. **Snap a Photo:** Residents photograph damaged sidewalk panels through our mobile app, automatically capturing geolocation.
2. **Community Votes:** The neighborhood votes on which panel matters most. The top-voted panel wins each month.
3. **Repair & Create:** A licensed crew fixes the panel. Then neighborhood kids and a teaching artist design and build a mosaic.
4. **Celebrate & Share:** We document the before and after, celebrate the young artists, and move to the next panel.

---

## Year 1 Pilot

- **Location:** Fairfax / Mid-City West neighborhood, Los Angeles
- **Panels:** 10 panels over 10 months
- **Youth Participants:** 60 to 100 neighborhood kids
- **Budget:** $38,700 total
- **Cost Per Panel:** $2,700 (concrete, tile, artist, permit)
- **Website:** [sidewalkstoriesla.org](https://sidewalkstoriesla.org)

## Website

This repository contains the source code for the Sidewalk Stories LA website, hosted on GitHub Pages with a custom domain.

### Pages
- **index.html** — Landing page with hero, stats, problem/solution, process, pilot details, gallery, CTA
- **about.html** — Mission, core values, team, origin story
- **program.html** — Detailed 4-step process, budget tables, quarterly timeline, scaling path
- **contact.html** — Contact form, donation tiers, sponsorship packages, newsletter signup
- **press-kit.html** — Media assets, fact sheet, founder bios, contact information
- **404.html** — Branded error page

### Tech Stack
- Static HTML5/CSS3/JS
- Responsive design with CSS Grid and Flexbox
- Custom CSS variables for brand colors
- Interactive before/after image slider
- Animated stat counters
- Mobile navigation with hamburger toggle
- Google Fonts (Inter + Playfair Display)
